# Changelog

This file records user-visible changes. BROWSKI is currently preparing version
`0.1.0`; no public release has been published.

## 0.1.0 — Unreleased

- Added a WXT/React Manifest V3 side panel with task controls, structured
  action traces, settings and explicit high-risk confirmations.
- Added authenticated Native Messaging and a bounded owned-tab debugger proxy
  that uses the existing Rust semantic browser engine.
- Added opt-in viewport vision and isolated semantic-data JavaScript
  transforms. Live page code, host I/O and unrestricted shell remain unavailable.
- Added optional privacy modes, local credential management, authenticated
  checkpoint encryption, source-bound explicit text transfers and local run
  counters.
- Added pre-dispatch observation checks and cancellation cleanup for lost
  browser sessions and stopped graph decisions.
- Added the Linux source installer and real packaged-Chromium software
  acceptance tests, including a multi-step form and supporting-tab demo.
- Added local release preparation for the locked Rust workspace, configured
  Python wheel, and production Chrome extension directory and archive.
- Added SHA-256 manifests for local release artifacts and a generated dependency
  license metadata inventory.
- Added a release checklist covering build, install, browser acceptance,
  dependency review, and platform evidence.

Luna is the active decision provider, Laya is shadow-only and Jev is disabled.
Browser acceptance uses deterministic provider fixtures. Live Luna task
quality, broad agent reliability and large-scale benchmarks remain unverified.
Supported scopes and platforms are governed by the README and architecture plan.
